REWIND

About the Project:
Rewind is a media website project designed to provide an engaging and user-friendly experience for exploring media content. The project focuses on creating a clear layout, appealing visual design, and straightforward navigation to make browsing the website enjoyable. It was developed as a web project, bringing together the website's structure, styling, and functionality to create a cohesive user experience. 

How It Was Built:
Rewind was developed using HTML, CSS, and JavaScript all within Visual Studio Code to create the website's layout, appearance, and interactive elements. The project is organised around its website files and assets, allowing the content, styling and functionality to work together. The implementation and design aim to make the website easy to navigate and accessible across different screen sizes. 

Features:
-- A dedicated media website experience. 
-- A visual interface designed for easy navigation. 
-- Website styling and layout focused on usability. 
-- Media-focused content and presentation.

How to Open It:
Simply just paste the link: https://24106.github.io/media-website/ into your web browser and explore the webite using its navigation and available interactive elements. Browse the media content and use the available features to interact with the website.
